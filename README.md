# Kwaw Ebenezer conference website

A responsive, buildless personal website for How Machines Learn.

## Personal photos
Place the selected portrait at assets/kwaw-portrait.jpg. The site currently shows initials until a photo is available. Do not use other people's photographs.

## Render
Push the contents of this directory to the intended GitHub repository. Create a Render Static Site linked to that repository. Publish directory: . (repository root). No dependencies are needed. If a build command is required, use: echo 'Static files ready'

Confirm the session slot before replacing the schedule notice. The conference dates are 10–12 November 2026. This site does not accept registrations or collect visitor information.

## Local preview
Run python3 -m http.server 8080 in this directory and open localhost:8080.
